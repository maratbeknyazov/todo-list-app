# Решение проблемы с погодой в эмуляторе Android

## Проблема
При попытке включить погоду появляется ошибка: **"failed to get the weather, please try again"**

## Причина
Эмулятор Android часто не имеет доступа к интернету или имеет проблемы с DNS.

Ваш API ключ **работает правильно**! URL запроса корректный:
```
https://api.openweathermap.org/data/2.5/weather?appid=9808c7dd4f096ccb910161ff73d3a573&q=London&units=metric&lang=en
```

## Решения (попробуйте по порядку):

### ✅ Решение 1: Используйте реальное устройство
Самый надёжный способ - запустить приложение на **реальном Android устройстве**:

1. Подключите телефон к компьютеру через USB
2. Включите "Отладка по USB" в настройках разработчика
3. Запустите: `flutter run`
4. Выберите ваше устройство из списка

На реальном устройстве погода **точно будет работать**.

---

### 🔧 Решение 2: Настройте интернет в эмуляторе

**Проверьте подключение:**
```bash
adb shell ping google.com
```

Если не работает:

1. **Перезапустите эмулятор** через Android Studio
2. **Проверьте настройки сети** в эмуляторе:
   - Settings → Network & Internet → Wi-Fi
   - Убедитесь, что Wi-Fi включен

3. **Используйте Google DNS:**
   ```bash
   adb shell settings put global dns1 8.8.8.8
   adb shell settings put global dns2 8.8.4.4
   ```

4. **Перезапустите эмулятор**

---

### 🧪 Решение 3: Проверьте API вручную

Откройте в браузере на **вашем компьютере**:
```
https://api.openweathermap.org/data/2.5/weather?appid=9808c7dd4f096ccb910161ff73d3a573&q=London&units=metric&lang=en
```

Если видите JSON с погодой - API работает, проблема только в эмуляторе.

---

### ⚙️ Решение 4: Увеличьте таймауты (уже сделано)

Мы увеличили таймауты до 15/20 секунд в `lib/config/api_strategy.dart`.
Перезапустите приложение и попробуйте снова.

---

## Рекомендация

**Лучший вариант:** Используйте **реальное Android устройство** для тестирования функций, требующих интернет (погода, обновления, синхронизация).

Эмуляторы отлично подходят для тестирования UI, но часто имеют проблемы с сетью.

## Проверка работы

После применения решений:
1. Откройте приложение
2. Settings → Turn on the weather
3. Введите: **London** (или любой город на английском)
4. Нажмите OK

Если всё работает, вы увидите погоду на главном экране! 🌤️
